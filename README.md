DompetKeluarga — situs anggaran rumah tangga untuk keluarga Indonesia: dasbor bulanan, pencatatan transaksi, anggaran per kategori, tujuan tabungan, dan laporan 6 bulan. Semua berjalan dari file statis, tanpa jaringan. Data yang tampil adalah data contoh keluarga fiktif; transaksi yang ditambahkan tersimpan di peramban sendiri.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080.
